# rodan-fileserver

A high-performance file sharing service for **Rodan**, designed to efficiently serve and manage challenge-related files.

## Features

- **Zero-copy file streaming** for fast downloads
- **JWT-based authentication** for secure access
- **Configurable payload limits and storage paths**
- **Graceful shutdown** and structured logging for reliability

The service is **fully implemented and production-ready**, with a modular design using **Actix Web** for scalability and performance.

It is intended for use in Rodan’s challenge ecosystem to **share large files efficiently and securely** between teams, while maintaining strict access control.
